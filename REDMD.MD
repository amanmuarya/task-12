#      Compound Interest Calculation

This project calculates the compound interest based on predefined static values using JavaScript.

##     Files included

- index.html - The main HTML structure

- style.css - The styling for the project
- script.js - The JavaScrip logic for compound interest calculation
- README.md` - Project information.

##      How to run:
1. Open `index.html in your web browser.
2. Check the console to see the calculatd compound interest.
